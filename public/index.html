An experiment

This is the last HTML page on this site.

Everything past the home screen is a .md file served straight off disk. No build step, no renderer, no HTML shell. Humans read it in the tab. Agents read the same bytes.

The claim

The web wraps text in HTML because 1993 browsers needed it. Agents don't. They strip the markup back off before they read anything, and the stripping is lossy and expensive.

So skip it. Write markdown, serve markdown, and see what breaks. The bet is that almost nothing does.

Try it

# what an agent gets
curl -sI localhost:4321/thesis | grep -i content-type
content-type: text/markdown; charset=utf-8

# what your browser gets, same bytes, different label
curl -sI -H 'Accept: text/html' localhost:4321/thesis | grep -i content-type
content-type: text/plain; charset=utf-8

One byte-for-byte payload. The Content-Type flips only because browsers download text/markdown instead of painting it. Add ?raw to force markdown anywhere.

The discovery chain

1robots.txtOpens the door, points at the map
2llms.txtHand-written index, every entry a .md URL
3sitemap.xmlSame URLs for crawlers that still want XML
4llms-full.txtThe whole site in one request
5*.mdThe content. Nothing between it and the reader
