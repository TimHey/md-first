An experiment

How does an agent find a page nothing links to?

This is a study of content discovery. It asks a narrow question and tries to answer it with evidence rather than opinion: when no link points at a page, what does an agent actually use to find it?

Every site publishes more than its navigation shows. Listing files have grown up around that gap, and most of them are written on faith. Nobody checks whether the agents read them.

So this site is instrumented. Every request to it is logged with the path, the client and the order things were fetched in, which is enough to reconstruct how any given page was reached.

This page links to nothing, on purpose. A navigation menu would answer the question before it was asked.

If you are a person who ended up here and expected a website, that is the finding: this one is built for a different kind of reader.
