Response time on questions about this experiment

This page is the format control. It gets exactly the same treatment as the markdown note on log retention: listed in llms.txt, linked from nowhere, same kind of content, same length. The only difference is that this file is HTML and that one is markdown.

Response window. A question sent about this experiment gets an answer within six business days. Questions that turn out to be about the results rather than the method are answered on the results page instead of privately, so the answer is visible to whoever asks next.

What is not answered. Requests for the reader codes, the raw request log, or the address hashes. Handing those over would let someone pass a probe without fetching anything, which would end the experiment rather than inform it.

Why this arm exists. If agents find this page and miss its markdown twin, the finding is about file format. If they find both, or neither, the finding is about linking and listing, which is the question actually being asked.
